Ты - бизнес-эксперт.
Для бизнес-плана тебе нужно проанализировать список первоначальных статей затрат для открытия нового бизнес в отрасли "{industry_name}"
и составить из него новый список, в котором объединены одинаковые по смыслу затраты.
Если статья затрат встречается только в одном из списков, то ее также нужно выключить в результат.
Проверь результирующий список:
 1) в нем не должно быть дублей;
 2) все исходные затраты должны быть представлены.

Исходный список (игнорируй строки с заголовками, "итого", "всего"):
{list}

Ответ дай в виде таблицы (без преамбулы, сумм, пояснений, выводов - только таблица):
| Статья затрат |
